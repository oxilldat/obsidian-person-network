# Person Network

Person Network превращает заметки о людях в интерактивную карту связей Obsidian. Плагин читает людей, фотографии, роли, компании, контакты и слои из frontmatter и отображает их на быстром canvas-графе. Граф доступен как самостоятельное представление и как вид внутри Bases.

[English version](README.md)

![Граф Person Network](image/graph-overview.gif)

## Возможности

- Определение людей по настраиваемому тегу и полям frontmatter.
- Отображение фотографий, имён, компаний, ролей, связей и потенциальных контактов.
- Расположение людей по ролям и дополнительное притяжение сотрудников одной компании друг к другу.
- Объединение людей в прозрачные пересекающиеся слои со своими названиями, идентификаторами, цветами и иконками Obsidian.
- Независимые наборы слоёв для обычного графа и каждого представления Bases.
- Поиск и фильтры по роли и компании прямо на графе.
- Настройка размера узлов, толщины линий и физики. Фильтры, физика, отображение и положение камеры сохраняются автоматически.
- Панорамирование, масштабирование, перетаскивание узлов, вписывание графа в окно и экспорт в PNG.
- Неразрушающая настройка отображаемой области фотографии.
- Предупреждения о повторяющихся именах, неизвестных ролях и нескольких заметках с `is_self`.
- Создание заметок для потенциальных контактов в выбранной папке по заданному шаблону.
- Автоматический выбор русского или английского языка по языку интерфейса Obsidian.

Симуляция сил и отрисовка останавливаются после стабилизации графа, поэтому в простое он не нагружает процессор.

## Установка

Установите **Person Network** через **Настройки → Сторонние плагины → Обзор**.

Для ручной установки:

1. Скачайте `main.js`, `manifest.json` и `styles.css` из последнего релиза GitHub.
2. Создайте в хранилище папку `.obsidian/plugins/person-network/`.
3. Скопируйте в неё три скачанных файла.
4. Включите Person Network в разделе сторонних плагинов.

## Быстрый старт

Создайте отдельную заметку для каждого человека и добавьте frontmatter:

```yaml
---
tags:
  - person
name: Иван Петров
photo: attachments/ivan.jpg
company: Север
relation: друг
potential_contacts:
  - Мария Сидорова
  - "[[Люди/Алексей Орлов|Алексей Орлов]]"
layers:
  - работа
  - близкий-круг
---
```

Откройте граф кнопкой на ленте или командой **«Открыть граф людей»**. Добавьте `is_self: true` в свою заметку, чтобы сделать её центральным узлом.

## Frontmatter

| Свойство | Тип | Назначение |
| --- | --- | --- |
| тег распознавания | тег | Добавляет заметку в Person Network. По умолчанию: `person`. |
| `name` | текст | Отображаемое имя. Если поле пустое, используется имя файла. |
| `photo` | текст | Путь к изображению внутри хранилища. |
| `relation` | текст | Выбирает роль из настроек плагина. |
| `company` | текст | Отображает компанию, используется в фильтре и для притяжения коллег. |
| `potential_contacts` | список | Имена или wikilinks. Существующие люди становятся связями, остальные — потенциальными контактами. |
| `layers` | список | Идентификаторы слоёв человека, например `[работа, семья]`. |
| `is_self` | логическое | Делает человека центральным узлом. |

Тег распознавания и названия полей `name`, `photo`, `relation`, `potential_contacts` и `layers` можно изменить. Поля `company` и `is_self` фиксированы.

## Роли

Роль определяет обводку человека и его положение относительно центра. У каждой роли есть цвет, сплошной/пунктирный/точечный стиль и показатель позиции от 1 до 10. Чем выше показатель, тем ближе человек к центру. Значение поля связи должно совпадать с названием роли. Для неизвестного значения применяется роль по умолчанию и показывается предупреждение.

![Настройки ролей](image/settings-roles.gif)

## Слои

Слои визуально объединяют людей и не влияют на физику графа. Создайте слой в разделе **Настройки → Person Network → Слои**, задайте ему уникальный идентификатор и добавьте этот идентификатор в общее поле слоёв нужных заметок:

```yaml
layers:
  - семья
  - проект-альфа
```

У слоя настраиваются название, идентификатор, цвет, иконка Obsidian, приоритет, отображение подписи и иконки. Слой минимум с двумя видимыми участниками рисуется как полупрозрачная область со скруглением. Области могут пересекаться, а приоритет определяет порядок отрисовки.

Кнопка слоёв на графе открывает компактную панель. Кнопка с глазом скрывает только область, а кнопка с человеком — участников. Через контекстное меню человека можно добавить его в слой или удалить из него. Плагин обновит общий список во frontmatter.

Наборы слоёв независимы для обычного графа и каждого представления Bases. Нужный набор выбирается параметром **«Отображение»** в настройках слоёв. Принадлежность людей всегда читается из одного общего поля frontmatter.

## Управление графом

Панель открывается кнопкой с шестерёнкой:

- **Фильтры** — поиск людей и фильтрация по роли или компании.
- **Отображение** — видимость линий связей и потенциальных контактов, размер узлов и толщина линий.
- **Силы** — длина и сила связей, отталкивание, притяжение к центру и притяжение по компаниям.

Кнопка с волшебной палочкой повторяет анимацию появления. Двойной клик по свободному месту вписывает видимые узлы в окно. Настройки панели и положение камеры сохраняются автоматически.

![Панель управления графом](image/control-panel.gif)

## Контакты и связи

Добавьте имена или wikilinks в поле контактов. Person Network сначала разрешает пути и псевдонимы заметок, затем сопоставляет имена. Совпавший человек становится связью. Если заметки ещё нет, появляется потенциальный контакт; нажмите на него, чтобы создать заметку в настроенной папке по выбранному шаблону.

## Настройка фотографии

Нажмите правой кнопкой мыши по человеку и выберите **«Настроить обрезку фото»**. Перемещайте изображение внутри квадрата, настройте масштаб и сохраните. Person Network записывает в локальный `data.json` только параметры отображения, не изменяя и не копируя исходный файл. Редактор доступен и для центрального человека с `is_self`.

## Интеграция с Bases

При включённом встроенном плагине Bases выберите **Person Network** как вид базы. Фильтры Bases определяют набор заметок, а параметры вида сопоставляют свойства имени, фото, связи и контактов. У каждого представления Bases собственный набор слоёв. Интеграцию можно отключить в настройках; для применения требуется перезапуск плагина или Obsidian.

![Person Network внутри Bases](image/bases-view.gif)

## Конфиденциальность

Person Network работает локально внутри хранилища. Плагин не выполняет сетевые запросы, не требует учётной записи, не показывает рекламу и не собирает телеметрию.
