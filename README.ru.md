# Person Network

Плагин для Obsidian, который рисует людей из вашего хранилища как интерактивную карту связей на canvas. Люди берутся из frontmatter заметок, располагаются по настраиваемой роли, соединяются по указанным контактам и управляются панелью прямо на графе, повторяющей раскладку встроенного вида «Граф» в Obsidian. Плагин также может работать как отдельный вид внутри Bases.

На других языках: [English](README.md)

## Возможности

- Отрисовка на canvas с собственной симуляцией сил без внешних зависимостей. Цикл анимации полностью останавливается, когда раскладка успокаивается, поэтому граф в простое не нагружает процессор.
- Люди определяются по одному настраиваемому тегу. Отдельный индекс или файл данных не нужен: всё берётся из frontmatter заметок.
- Роли сопоставляют значение связи (например, друг, семья, коллега) с цветом обводки, стилем обводки (сплошная, пунктирная, точечная) и показателем позиции от 1 до 10, который задаёт, насколько близко человек находится к центру.
- Центральный узел представляет вас: он берётся из заметки с пометкой `is_self`, либо используется обобщённый узел, если такой заметки нет.
- На узлах отображаются фотографии: они декодируются один раз и уменьшаются для экономии памяти. Если фото нет или оно не загрузилось, показывается силуэт.
- Фотографии сохраняют пропорции. По правому клику можно выбрать отображаемый квадрат, перемещая фото и меняя масштаб; настройка хранится в данных плагина и не изменяет файл.
- Потенциальные контакты: имена, указанные в заметке, у которых ещё нет собственной заметки, отображаются как отдельные призрачные узлы. Клик по призраку предлагает создать его заметку.
- Линии связей рисуются между людьми, которые ссылаются друг на друга по имени.
- Панель управления прямо на графе с поиском, фильтрами по типу связи и компании, параметрами отображения и ползунками сил, оформленная как во встроенном виде «Граф».
- Анимация появления: узлы проявляются и вырастают от центра к краям, после чего проступают связи.
- Вписывание в окно, плавное кадрирование камеры, панорамирование, зум колесом, перетаскивание узлов и повторное вписывание по двойному клику.
- Фильтры, параметры сил, настройки отображения и положение камеры сохраняются между открытиями графа.
- Предупреждения о данных показывают повторяющиеся имена, неизвестные роли и несколько заметок с `is_self`.
- Экспорт текущего вида в изображение PNG.
- Интеграция с Bases: граф доступен как тип вида внутри Bases, где фильтры базы определяют, кто попадает на карту.
- Поддержка светлой, тёмной и пользовательских тем. Все цвета берутся из CSS-переменных Obsidian.
- Русский и английский интерфейс, определяется автоматически по языку Obsidian.

## Установка

Установите **Person Network** через **Настройки → Сторонние плагины → Обзор** в Obsidian.

### Вручную

1. Скачайте `main.js`, `manifest.json` и `styles.css` из последнего релиза.
2. Создайте папку `person-network` внутри хранилища по пути `.obsidian/plugins/`.
3. Положите три файла в эту папку.
4. Откройте настройки, перейдите в раздел сторонних плагинов и включите Person Network.

## Начало работы

Создайте заметку человека и добавьте frontmatter с тегом распознавания:

```yaml
---
tags:
  - person
name: Иван Петров
photo: attachments/ivan.jpg
company: Acme Corp
relation: друг
potential_contacts:
  - Мария Сидорова
  - Кайл Риз
---
```

Откройте граф иконкой на ленте или командой «Открыть граф людей». Заметка с тегом `person` становится узлом. Чтобы отметить себя как центр, добавьте `is_self: true` в свою заметку.

## Справочник по frontmatter

| Поле | Тип | Описание |
| --- | --- | --- |
| тег распознавания | тег | Помечает заметку как человека. Тег по умолчанию `person`, настраивается. |
| `name` | текст | Отображаемое имя. Если не указано, берётся имя файла. |
| `photo` | текст | Путь к фото внутри хранилища. |
| `relation` | текст | Название роли. Стиль обводки и позиция берутся из списка ролей. |
| `company` | текст | Используется фильтром по компании и показывается под узлом. |
| потенциальные контакты | список | Имена контактов. Имя со своей заметкой становится связью; имя без заметки — призрачным узлом. |
| `is_self` | логическое | Помечает заметку как вас. Этот узел становится центром. |

Все имена полей, кроме `is_self` и `company`, настраиваются в параметрах.

## Роли

Роль связывает то, как человек выглядит, и то, где он находится. У каждой роли есть цвет, стиль обводки и показатель позиции от 1 до 10, где 10 — ближе всего к центру. Значение `relation` в заметке выбирает её роль. Любая заметка, чья связь не совпала с заданной ролью, использует роль по умолчанию.

## Панель управления на графе

Панель открывается иконкой шестерёнки в углу графа и повторяет структуру встроенного вида «Граф».

- Фильтры: поле поиска с подсветкой и затемнением, а также переключатели для каждого типа связи и компании.
- Отображение: переключатели линий связей и потенциальных контактов, а также ползунки размера узлов и толщины связей.
- Силы: ползунки силы отталкивания, силы связей, длины связей и силы притяжения.

Иконка с палочкой повторяет анимацию появления, а иконка сброса возвращает элементы панели к значениям по умолчанию.

Состояние панели и положение камеры сохраняются автоматически.

## Потенциальные контакты

Укажите контакты человека в поле контактов. Если имя совпадает с другой заметкой человека, между ними рисуется линия связи. Если у имени ещё нет заметки, оно отображается приглушённым призрачным узлом с пунктирной обводкой. Клик по призраку открывает запрос на создание его заметки с использованием настроенных папки и шаблона.

Контакты также могут быть wikilinks, например `[[People/Иван Петров|Иван]]`: сначала плагин разрешает путь заметки и только затем сопоставляет отображаемое имя.

## Кадрирование фотографий

Нажмите правой кнопкой мыши по человеку с фотографией и выберите **«Настроить обрезку фото»**. Перемещайте изображение внутри квадрата и настройте масштаб, затем сохраните область отображения. Исходное изображение не изменяется, копии не создаются. Параметры хранятся в локальном `data.json` плагина с привязкой к пути заметки.

## Интеграция с Bases

Когда включён core-плагин Bases, Person Network регистрирует тип вида графа, который можно выбрать внутри любой базы. Фильтры базы определяют, какие заметки появляются на карте, а параметры вида в тулбаре Bases сопоставляют свойства имени, фото, связи и контактов. Это можно отключить в настройках.

![alt text](image/bases-view.gif)

## Настройки

- Определение людей: тег распознавания и имена полей для имени, фото, связи и контактов, а также исключаемые пути.
- Роли: добавление, изменение и удаление ролей, а также настройка роли по умолчанию.
- Общее: подпись центрального узла и переключатель интеграции с Bases.
- Новые заметки: папка и заметка-шаблон, используемые при создании заметки из призрака.

## Конфиденциальность

Person Network работает только с файлами внутри вашего хранилища. Плагин не выполняет сетевые запросы, не требует учётной записи, не показывает рекламу и не собирает телеметрию.
